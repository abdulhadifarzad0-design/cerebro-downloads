# Cerebro

**Learn one interface. Use every app.** Tell Cerebro what you want to make; it finds the few controls you need in the app you have open, lays them out step by step, and its buttons work the real app.

## Download

Get the latest files from **[Releases](https://github.com/abdulhadifarzad0-design/cerebro-downloads/releases/latest)**:

| File | What it is |
|---|---|
| `Cerebro-macOS-arm64.zip` | The Mac app (Apple Silicon). Unzip, move to Applications, open. If macOS says it can't verify Cerebro, go to **System Settings › Privacy & Security** and click **Open Anyway**. |
| `Cerebro-Chrome-Extension.zip` | For web apps. Unzip, open `chrome://extensions`, turn on Developer mode, click **Load unpacked**. |
| `cerebro_bridge-0.1.0.zip` | Blender 4.2+ plugin. **Edit › Preferences › Get Extensions › Install from Disk**. |

Cerebro is an early prototype. This repository only hosts downloads.
